# 招待

家計簿への参加を許可する一回限りの URL。管理者が発行し、招待 URL を経由して新しいメンバーが家計簿に参加する。

## ユースケース

- 招待 URL を発行する（管理者のみ。既存の有効 URL は自動無効化）
- 招待 URL で家計簿に参加する（任意の認証済みユーザー、ただし所属なしの場合のみ）

## 主な業務制約

- 有効期限: 発行から **24 時間**（要件定義書 §4.1, §5.3）
- 利用回数: **1 回限り**（受諾もしくは期限経過・新規発行で無効化）
- 同時に有効な招待 URL は **1 本のみ**（新規発行で既存を自動無効化）
- トークンは **128 bit 以上の推測困難な乱数**（要件定義書 §5.3）
