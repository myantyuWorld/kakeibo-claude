# 対訳表（ユビキタス言語）

家計簿アプリで使う日本語の業務用語と、コード上の英語名の対応を集約する。
コード実装・API 設計・テストの命名根拠となるため、各ドメインで新しい用語を導入する際は本ファイルを必ず更新する。

## 横断的な用語

| 日本語 | 英語（コード） | 備考 |
|--------|-------------|------|
| ID | ID | 全エンティティの主キー（UUID）。外部公開は UUID のみ |
| 作成日時 | CreatedAt | レコード作成時刻（タイムスタンプ） |
| 更新日時 | UpdatedAt | レコード最終更新時刻 |
| 暦月 | CalendarMonth | 1 日〜末日固定。月次集計・固定費自動コピー・予算判定の基準（要件定義書 §6.1） |
| ロール | Role | ユーザーが家計簿に対して持つ権限種別（Admin / Member） |
| 退会済みユーザー表示 | WithdrawnUserLabel | 退会済みユーザーが過去に作成したデータの所有者・送信者として表示するラベル |

## ユーザー (User)

| 日本語 | 英語（コード） | 備考 |
|--------|-------------|------|
| ユーザー | User | 集約ルート |
| LINE ユーザー ID | LineUserID | LINE OIDC の `sub` クレーム。外部に露出しない |
| ニックネーム | Nickname | 表示名。プロフィール登録で必須 |
| サムネ画像 URL | ThumbnailURL | 画像 URL（外部ストレージ参照）。任意 |
| プロフィール | Profile | ニックネーム + サムネ画像（概念上の括り） |
| 通知設定 | NotificationSetting | Push 通知の ON/OFF |
| 通知 ON/OFF フラグ | PushNotificationEnabled | bool。デフォルト true |
| 退会 | Withdraw | アカウントのソフト削除 |
| ユーザー状態 | UserStatus | Active / Withdrawn |

## 家計簿 (Household)

| 日本語 | 英語（コード） | 備考 |
|--------|-------------|------|
| 家計簿 | Household | 集約ルート |

## メンバーシップ (Membership)

| 日本語 | 英語（コード） | 備考 |
|--------|-------------|------|
| メンバーシップ | Membership | 集約ルート。家計簿とユーザーの所属関係 |
| ロール | Role | Admin / Member。v1 では作成後の変更不可 |
| 管理者 | Admin | 家計簿の作成者。1 家計簿に 1 人 |
| メンバー | Member | 管理者から招待されて家計簿に所属するユーザー |
| 参加日時 | JoinedAt | Membership 作成日時。CreatedAt と同義 |

## 招待 (Invitation)

| 日本語 | 英語（コード） | 備考 |
|--------|-------------|------|
| 招待 | Invitation | 集約ルート |
| 招待 URL | InvitationURL | フロント側で `https://liff.app/...?token=xxx` 形式で生成 |
| 招待トークン | InvitationToken | 推測困難な乱数（128 bit 以上、base64url）。一意 |
| 発行者 | IssuedByUserID | 招待 URL を発行した管理者の UserID |
| 招待状態 | InvitationStatus | Pending / Used / Expired / Revoked |
| 有効期限 | ExpiresAt | 発行時刻 + 24 時間 |
| 使用日時 | UsedAt | 招待 URL が消費された時刻 |
| 使用者 | UsedByUserID | 招待 URL を使って参加したユーザー |

## 個人カテゴリ設定 (UserCategoryPreference)

| 日本語 | 英語（コード） | 備考 |
|--------|-------------|------|
| 個人カテゴリ設定 | UserCategoryPreference | 集約ルート。ユーザー × カテゴリの個別設定 |

## 収支明細 (Entry)

| 日本語 | 英語（コード） | 備考 |
|--------|-------------|------|
| 収支明細 | Entry | 集約ルート。1 件の収入または支出 |
| 区分 | EntryKind | 収入 / 支出。`Category.Kind` から派生（Entry 自体には保持しない） |
| 金額 | Amount | 値オブジェクト。JPY、NUMERIC 型、1 円〜 |
| 日付 | EntryDate | 暦日（DATE 型）。明細の発生日 |
| メモ | Memo | 任意、最大 200 文字 |
| 所有者 | Owner / OwnerUserID | 「誰の収支か」を表すユーザー ID。代理入力可 |
| 登録者 | CreatedByUserID | 操作者本人。代理入力時は Owner と異なる |
| 代理入力 | ProxyEntry | 登録者 ≠ 所有者となる登録方法 |
| 固定費自動コピー | MonthlyFixedCostCopy | 月初バッチで前月の固定費明細を当月にコピーする処理 |
| 月初バッチ | MonthlyBatch | 毎月 1 日 0:00 起動の定期処理（スケジューラ） |
| CSV インポート | CSVImport | 管理者が過去明細を CSV から取り込む操作。重複検知あり |

## チャット (ChatMessage)

| 日本語 | 英語（コード） | 備考 |
|--------|-------------|------|
| チャット | Chat | 家計簿のグループチャット機能の総称 |
| チャットメッセージ | ChatMessage | 集約ルート。1 件のメッセージ |
| 本文 | MessageBody | 値オブジェクト。1〜500 文字 |
| 送信者 | SenderUserID | メッセージの送信ユーザー |
| 既読 | ChatRead | 集約ルート。メッセージ × ユーザーごとの既読レコード |
| 既読日時 | ReadAt | 自動既読化された時刻 |
| 自動既読化 | AutoMarkAsRead | チャット画面表示時にサーバーで自動 INSERT する仕様（LINE 風、QA-H2） |
| オンライン状態 | OnlineStatus | 集約ルート。各ユーザーの最終アクセス時刻 |
| 最終アクセス日時 | LastSeenAt | OnlineStatus の更新基準 |
| オンラインしきい値 | OnlineThreshold | 最終アクセスから N 分以内をオンラインと判定。暫定 5 分 |
| Push 通知配信 | PushNotificationDispatch | 送信時に通知 ON の受信メンバーへ LINE 公式アカウント経由で配信する処理 |
