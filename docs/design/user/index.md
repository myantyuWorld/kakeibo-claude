# ユーザー

LINE ログインで認証する利用者。プロフィール（ニックネーム・サムネ画像）と Push 通知設定を持つ。

## 下流ドメインへの影響

- **メンバーシップ (Membership)**: ユーザーは家計簿に所属する（User.ID を参照）
- **収支明細 (Entry)**: 明細の所有者として参照される（User.ID を参照）
- **招待 (Invitation)**: 招待 URL の発行者として参照される（User.ID を参照）
- **チャット (ChatMessage)**: メッセージの送信者・既読者として参照される（User.ID を参照）

退会後は他ドメインで「退会済みユーザー」として表示される（所有者・送信者の参照は維持）。

## ユースケース

- LINE でログインする（初回時はユーザー作成）
- プロフィールを登録・編集する（ニックネーム・サムネ画像）
- 通知設定を変更する（Push 通知 ON/OFF）
- アカウントを退会する
