# 収支明細

家計簿に登録される 1 件の収入または支出。日付・カテゴリ・金額・メモ・所有者（誰の収支か）を持つ。
代理入力（登録者と所有者が異なる）と固定費の月初自動コピーを扱う、本アプリの中核ドメイン。

## ユースケース

- 収支を登録する（代理入力可、所有者は同家計簿の Active メンバーから選択）
- 収支明細を編集する（所有者の変更は不可、それ以外は編集可）
- 収支明細を削除する
- 月内・月別・カテゴリ別・メンバー別の集計を取得する（視覚化の元データ）
- CSV から収支明細をインポートする（管理者のみ、重複検知あり）
- 固定費を月初に自動コピーする（システムが月初に実行）

## 主な業務制約

- メンバー全員が所属家計簿の全 Entry を閲覧・編集・削除可能（所有者を問わず）
- 代理入力: 所有者は同家計簿の Active メンバーから選択可（退会済みユーザーへの代理入力は不可）
- **所有者は登録時のみ指定可能、編集での変更は不可**
- 集計は暦月（1 日〜末日）固定
- CSV インポートは管理者限定、重複検知あり
- 固定費自動コピーは月初バッチで実行、各メンバー × 各支出カテゴリで前月明細をそのメンバー自身の当月にコピー
