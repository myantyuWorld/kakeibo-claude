# 家計簿 - 業務ルール

## スコープ

家計簿ドメインが扱う範囲:

- 家計簿の作成・名前変更・削除
- 削除時の下流ドメインデータの一括カスケード削除

家計簿ドメインのスコープ外:

- 所属メンバーの管理（→ [メンバーシップ](../membership/index.md)）
- 招待 URL の発行・消費（→ [招待](../invitation/index.md)）
- カテゴリ・予算・収支明細・チャットの内容（各ドメイン）

## Household のライフサイクル

| 状態 | 説明 |
|------|------|
| Active | 利用可能。レコードが存在する状態 |
| 削除済み | 物理削除（レコードが消える）。下流ドメインも `ON DELETE CASCADE` で連鎖削除 |

遷移ルール:

- `[未存在] → Active`: 作成（Create）。同時に Admin Membership が作成される
- `Active → 削除済み`: 削除（Delete）。管理者のみ実行可。関連データ全削除

## 共通バリデーション

### 文字数制約

| フィールド | 制約 | 備考 |
|-----------|------|------|
| HouseholdName | 1〜50 文字 | 必須 |

## 家計簿を作成する

### ビジネスルール

- 認証済みユーザー本人のみ実行可能
- 1 ユーザーは 1 家計簿のみ所属（メンバーシップの `UserID` 一意制約で保証）
  - 既にメンバーシップを持つユーザーは作成不可（事前バリデーション）
- 作成と同時に、その操作者を `Admin` ロールのメンバーシップとして登録する
  - Household 作成と Admin Membership 作成は同一トランザクションで実行する
- 作成時、システムが用意するデフォルトの収入・支出カテゴリを家計簿にコピーする（カテゴリドメインの責務、Round 3 で詳細化）

## 家計簿名を編集する

### ビジネスルール

- 管理者のみ実行可能
- HouseholdName のバリデーションは共通制約に従う

## 家計簿を削除する

### ビジネスルール

- 管理者のみ実行可能
- 削除すると以下のすべてのデータが物理削除される（DB の `ON DELETE CASCADE` で連鎖）:
  - メンバーシップ（自身を含む全メンバー）
  - 招待（Pending / Used / Expired / Revoked すべて）
  - カテゴリ
  - 個人カテゴリ設定
  - 収支明細
  - 予算
  - チャットメッセージ・既読・オンライン状態
- 削除後はメンバーだったユーザーは家計簿に所属していない状態となり、新たに家計簿を作成 or 招待 URL から参加できるようになる
- 退会済みユーザーが所有していた明細・送信していたチャットも一緒に削除される

## 受入基準

### 家計簿を作成する

**正常系: メンバーシップを持たないユーザーが作成**

- Given: 認証済み User（プロフィール登録済み）、所属家計簿なし
- When: HouseholdName を指定して作成 API を呼ぶ
- Then: Household が作成され、同じトランザクション内で操作者の Admin Membership が作成される。デフォルトカテゴリが家計簿にコピーされる

**異常系: 既にメンバーシップを持つユーザーが作成**

- Given: 認証済み User、所属家計簿あり（ロール問わず）
- When: 作成 API を呼ぶ
- Then: バリデーションエラー（既に家計簿に所属しています）

**異常系: HouseholdName が空 / 51 文字以上**

- Given: 認証済み User
- When: 空または 51 文字以上の HouseholdName で作成 API を呼ぶ
- Then: バリデーションエラー（家計簿名は 1〜50 文字）

**異常系: プロフィール未登録のユーザー**

- Given: 認証済み User、`Nickname` 空
- When: 作成 API を呼ぶ
- Then: バリデーションエラー（先にプロフィールを登録してください）

### 家計簿名を編集する

**正常系: 管理者が編集**

- Given: 管理者ロールの認証済みユーザー
- When: 新しい HouseholdName を指定して更新 API を呼ぶ
- Then: HouseholdName が保存される

**異常系: メンバーが編集を試みる**

- Given: メンバーロールの認証済みユーザー
- When: 更新 API を呼ぶ
- Then: 認可エラー（権限がありません）

### 家計簿を削除する

**正常系: 管理者が削除**

- Given: 管理者ロールの認証済みユーザー
- When: 削除 API を呼ぶ
- Then: Household が物理削除され、すべての下流ドメインのデータも連鎖削除される。操作者の Membership も削除されるため、他の家計簿への参加・新規作成が可能になる

**異常系: メンバーが削除を試みる**

- Given: メンバーロールの認証済みユーザー
- When: 削除 API を呼ぶ
- Then: 認可エラー（権限がありません）

**正常系: 退会済みユーザーが所有していた明細を含む家計簿の削除**

- Given: 管理者ロールの認証済みユーザー、家計簿内に退会済みユーザーの明細・チャットが存在
- When: 削除 API を呼ぶ
- Then: 退会済みユーザーのデータも含めて連鎖削除される（要件定義書 §6.4）
