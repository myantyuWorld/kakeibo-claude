# 家計簿

収支を共有管理する単位。1 ユーザーが家計簿を作成すると、その作成者は管理者ロールを得る（[メンバーシップ](../membership/index.md) を参照）。

## 関連ドキュメント

- [ドメインモデル](ドメインモデル.md) - エンティティ・集約の構造と関係
- [業務ルール](業務ルール.md) - ビジネスルール・制約・受入基準
- 共通: [対訳表（ユビキタス言語）](../対訳表.md#家計簿-household)
- API 仕様書 - 未作成

## 上流ドメイン

- [ユーザー (User)](../user/index.md) - 家計簿の作成者・所属者として参照

## 下流ドメイン

- [メンバーシップ (Membership)](../membership/index.md) - 家計簿への所属関係
- [招待 (Invitation)](../invitation/index.md) - 家計簿への招待 URL
- [カテゴリ (Category)](../) - 収支の分類（Round 3 で作成）
- [収支明細 (Entry)](../) - 収入・支出の明細（Round 4 で作成）
- [予算 (Budget)](../) - 月次予算（Round 4 で作成）
- [チャット (ChatMessage)](../) - グループチャット（Round 5 で作成）

家計簿削除時、上記の下流ドメインのデータはすべて DB の `ON DELETE CASCADE` で一括削除される。

## ユースケース

- 家計簿を作成する（作成者は同時に管理者となる）
- 家計簿名を編集する（管理者のみ）
- 家計簿を削除する（管理者のみ。関連データすべてカスケード削除）
