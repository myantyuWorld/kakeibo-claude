# 個人カテゴリ設定

家計簿のカテゴリに対する、ユーザーごとの個別設定。表示／非表示・並び順・固定費フラグを持つ。

レコードは Lazy 作成（ユーザーが設定を変更したときに初めて作成される）。
レコードが存在しない場合は **デフォルト値**（表示=ON、並び順=カテゴリ作成順、固定費=OFF）として扱う。

## ユースケース

- カテゴリの表示／非表示を切り替える
- 支出カテゴリの並び順を変更する
- 支出カテゴリを「固定費」として設定する／解除する

## 主な業務制約

- 個人レベル: 自分の設定のみ操作可能（他人の設定は閲覧・編集不可）
- 固定費フラグは支出カテゴリ（Kind=Expense）のみ ON 可能
- 固定費フラグ ON にした月の月初自動コピーは対象外（翌月以降から有効、QA-F2-b）
