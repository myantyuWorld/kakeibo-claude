# 予算 - 業務ルール

## スコープ

予算ドメインが扱う範囲:

- 月次予算の設定・編集・削除（管理者操作）
- 視覚化用の予算ライン提供

スコープ外:

- 予算超過時の登録画面でのリアルタイム警告（QA-E1 で「出さない」確定）
- 予算と実績の集計ロジック（→ 視覚化層 / Entry ドメインのクエリと組み合わせ）
- 収入カテゴリの予算（v1 では未対応）

## Budget のライフサイクル

| 状態 | 説明 |
|------|------|
| Active | 予算が設定されている状態。レコードが存在 |
| 削除済み | 物理削除（個別削除、または Household / Category 削除のカスケード） |

遷移ルール:

- `[未存在] → Active`: 管理者の設定
- `Active → Active`: 上書き設定（UPSERT。実体は UPDATE）
- `Active → 削除済み（個別）`: 管理者の削除
- `Active → 削除済み（カスケード）`: Household または Category 削除

## 共通バリデーション

### 値範囲

| フィールド | 制約 | 備考 |
|-----------|------|------|
| BudgetAmount | 1〜999,999,999 円 | NUMERIC 型、整数のみ |
| YearMonth.Year | 妥当な西暦年 | 過去・未来とも許容 |
| YearMonth.Month | 1〜12 | |

### 整合性

- `CategoryID` は `HouseholdID` と同じ家計簿のカテゴリ
- `Category.Kind = Expense` でなければならない
- `(HouseholdID, CategoryID, YearMonth)` で一意

## 月次予算を設定する

### ビジネスルール

- 管理者のみ実行可能
- `CategoryID`、`YearMonth`、`Amount` を指定して設定（UPSERT）
- 既存予算がある場合は金額を上書き

## 月次予算を編集する

### ビジネスルール

- 管理者のみ実行可能
- 「設定」と同じ UPSERT 操作で実現する想定（個別 API を分けない選択肢）
- 編集可能項目: `BudgetAmount` のみ
- `(HouseholdID, CategoryID, YearMonth)` は予算の同一性を表すため変更不可（変えたい場合は削除＋新規）

## 月次予算を削除する

### ビジネスルール

- 管理者のみ実行可能
- 物理削除
- 削除後はそのカテゴリ × 月の予算ラインが視覚化から消える

## 受入基準

### 月次予算を設定する

**正常系: 新規設定**

- Given: 管理者 A、家計簿 H、Expense カテゴリ「食費」、2026-05 の予算なし
- When: `CategoryID=食費, YearMonth=2026-05, Amount=50000` で設定 API を呼ぶ
- Then: Budget が新規作成される

**正常系: 既存予算の上書き**

- Given: 管理者 A、`CategoryID=食費, YearMonth=2026-05` の Budget(Amount=50000) あり
- When: `Amount=60000` で設定 API を呼ぶ
- Then: 既存 Budget が UPDATE され、Amount=60000 が保存される（同一 ID）

**異常系: メンバーが設定を試みる**

- Given: メンバー B
- When: 設定 API を呼ぶ
- Then: 認可エラー（権限がありません）

**異常系: 収入カテゴリへの予算設定**

- Given: 管理者 A、Income カテゴリ「給与」
- When: `CategoryID=給与` で設定 API を呼ぶ
- Then: バリデーションエラー（予算は支出カテゴリにのみ設定できます）

**異常系: 別家計簿のカテゴリへの予算設定**

- Given: 管理者 A（家計簿 H1）、カテゴリは家計簿 H2 のもの
- When: 設定 API を呼ぶ
- Then: バリデーションエラー（カテゴリが家計簿に存在しません）

**異常系: Amount が 0 または負**

- Given: 管理者 A
- When: `Amount=0` または `Amount=-1` で設定
- Then: バリデーションエラー（予算金額は 1 円以上）

### 月次予算を削除する

**正常系: 管理者が削除**

- Given: 管理者 A、対象 Budget あり
- When: 削除 API を呼ぶ
- Then: Budget が物理削除される。視覚化グラフから該当カテゴリ × 月の予算ラインが消える

**異常系: メンバーが削除を試みる**

- Given: メンバー B
- When: 削除 API を呼ぶ
- Then: 認可エラー（権限がありません）

### カテゴリ削除のカスケード

**正常系: カテゴリ削除に伴う予算の連鎖削除**

- Given: 管理者 A、Expense カテゴリ「副業（誤入力）」、2026-05 の予算あり、Entry なし
- When: そのカテゴリを削除
- Then: カテゴリと Budget の両方が削除される（DB の `ON DELETE CASCADE`）

### 視覚化との連携（参考）

**正常系: 予算あり → 累積グラフに予算ライン併記**

- Given: 2026-05 の食費予算 50,000 円が設定済み
- When: 月内累積支出グラフ（食費・2026-05）を表示
- Then: 累積支出折れ線に加えて、50,000 円の水平な予算ラインが描画される

**正常系: 予算なし → 累積ラインのみ（QA-E2）**

- Given: 2026-05 の食費予算なし
- When: 月内累積支出グラフ（食費・2026-05）を表示
- Then: 累積支出折れ線のみ描画される
