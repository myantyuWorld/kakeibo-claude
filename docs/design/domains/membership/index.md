# メンバーシップ

ユーザーと家計簿の所属関係を表す。ロール（Admin / Member）を持つ。

家計簿を作成したユーザーは自動的に Admin ロールのメンバーシップを得る。
他のユーザーは [招待 URL](../invitation/index.md) を経由して Member ロールで参加する。

## 下流ドメイン

なし（他ドメインは UserID / HouseholdID で直接ユーザー・家計簿を参照する）

## ユースケース

- 家計簿のメンバー一覧を確認する
- （副次的）家計簿作成時に Admin メンバーシップを作成する
- （副次的）招待 URL 受諾時に Member メンバーシップを作成する

> v1 ではメンバーシップの自発的脱退・管理者による除外・ロール変更（権限委譲）はスコープ外（要件定義書 §1.3）。
