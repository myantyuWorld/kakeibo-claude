# カテゴリ - 業務ルール

## スコープ

カテゴリドメインが扱う範囲:

- 家計簿レベルのカテゴリ（収入・支出）の追加・編集・削除
- 家計簿作成時のデフォルトカテゴリ自動コピー
- カテゴリ削除時の Entry 参照チェック

カテゴリドメインのスコープ外:

- カテゴリの表示／非表示・並び順・固定費フラグ（→ [個人カテゴリ設定](../user-category-preference/index.md)）
- 月次予算の管理（→ [予算](../) Round 4 で作成）
- 月初の固定費自動コピー（→ [収支明細](../) Round 4 で作成）

## Category のライフサイクル

| 状態 | 説明 |
|------|------|
| Active | 利用可能。レコードが存在する状態 |
| 削除済み | 物理削除。家計簿削除（カスケード）または個別削除（明細なしの場合のみ） |

遷移ルール:

- `[未存在] → Active`: 管理者による追加、もしくは家計簿作成時のデフォルトカテゴリコピー
- `Active → 削除済み（個別）`: 管理者が削除。Entry 参照なしの場合のみ
- `Active → 削除済み（カスケード）`: Household の削除に伴う `ON DELETE CASCADE`

## 共通バリデーション

### 文字数制約

| フィールド | 制約 | 備考 |
|-----------|------|------|
| CategoryName | 1〜30 文字 | 必須 |

### 一意制約

- `(HouseholdID, Kind, Name)` は一意 — 同じ家計簿・同じ種別でカテゴリ名の重複を許さない

## デフォルトカテゴリの自動コピー

### ビジネスルール

家計簿作成と同じトランザクション内で実行する（→ [家計簿の作成](../household/業務ルール.md#家計簿を作成する)）。

システムが用意するデフォルトカテゴリ一覧（暫定 — 実装時に最終確定）:

- **収入**: 給与、賞与、副業、その他
- **支出**: 食費、日用品、光熱費、通信費、住居費、交通費、医療費、娯楽、衣服、教育、その他

これらを新規 Household の Category として一括 INSERT する。コピー後、管理者は自由に追加・編集・削除できる。

## カテゴリを追加する

### ビジネスルール

- 管理者のみ実行可能
- `Kind`（Income / Expense）と `Name` を指定して新規作成
- 同一家計簿・同一種別で同名カテゴリが既に存在する場合は拒否

## カテゴリを編集する

### ビジネスルール

- 管理者のみ実行可能
- 編集可能なのは `Name` のみ。`Kind` は作成後変更不可
- 同一家計簿・同一種別で同名カテゴリが既に存在する場合は拒否

## カテゴリを削除する

### ビジネスルール

- 管理者のみ実行可能
- 削除前に「そのカテゴリを参照する Entry が 1 件でも存在するか」をチェックする
  - 存在する場合: 削除拒否（QA-D1: 「先に明細のカテゴリを付け替える運用」）
  - 存在しない場合: 削除実行
- 削除すると、関連する UserCategoryPreference・Budget は `ON DELETE CASCADE` で連鎖削除される
- 退会済みユーザーの Entry も参照チェックの対象（退会済みでも明細は残るため）

## 受入基準

### カテゴリを追加する

**正常系: 管理者が新規追加**

- Given: 管理者ロールのユーザー、家計簿に「食費」（Expense）なし
- When: `Kind=Expense, Name="食費"` で追加 API を呼ぶ
- Then: Category が作成される

**異常系: 同名カテゴリが既存**

- Given: 管理者ロールのユーザー、家計簿に「食費」（Expense）あり
- When: `Kind=Expense, Name="食費"` で追加 API を呼ぶ
- Then: バリデーションエラー（同名のカテゴリが既に存在します）

**正常系: 種別が異なれば同名可**

- Given: 管理者ロールのユーザー、家計簿に「その他」（Income）あり
- When: `Kind=Expense, Name="その他"` で追加 API を呼ぶ
- Then: Category が作成される（種別が異なるため重複扱いにならない）

**異常系: メンバーが追加を試みる**

- Given: メンバーロールのユーザー
- When: 追加 API を呼ぶ
- Then: 認可エラー（権限がありません）

**異常系: CategoryName が空 / 31 文字以上**

- Given: 管理者ロールのユーザー
- When: 空または 31 文字以上の `Name` で追加 API を呼ぶ
- Then: バリデーションエラー（カテゴリ名は 1〜30 文字）

### カテゴリを編集する

**正常系: 管理者がカテゴリ名変更**

- Given: 管理者ロールのユーザー、Category「食費」あり
- When: Name="食費（外食含む）" で更新 API を呼ぶ
- Then: Name が保存される

**異常系: 編集後の名前が既存と重複**

- Given: 管理者ロールのユーザー、家計簿に「食費」「日用品」あり
- When: 「日用品」を編集して「食費」に変更
- Then: バリデーションエラー（同名のカテゴリが既に存在します）

**異常系: メンバーが編集を試みる**

- Given: メンバーロールのユーザー
- When: 更新 API を呼ぶ
- Then: 認可エラー（権限がありません）

### カテゴリを削除する

**正常系: 明細なしのカテゴリ削除**

- Given: 管理者ロールのユーザー、Category「副業」（Income）に紐付く Entry なし
- When: 削除 API を呼ぶ
- Then: Category が物理削除される。関連する UserCategoryPreference・Budget も連鎖削除される

**異常系: 明細ありのカテゴリ削除拒否**

- Given: 管理者ロールのユーザー、Category「食費」に紐付く Entry 1 件以上あり
- When: 削除 API を呼ぶ
- Then: バリデーションエラー（このカテゴリには明細が紐付いているため削除できません。先に明細のカテゴリを付け替えてください）

**異常系: 退会済みユーザーの明細でも削除拒否**

- Given: 管理者ロールのユーザー、Category「食費」に紐付く Entry が退会済みユーザー所有のみ存在
- When: 削除 API を呼ぶ
- Then: バリデーションエラー（退会済みユーザーの明細も残っているため削除不可）

**異常系: メンバーが削除を試みる**

- Given: メンバーロールのユーザー
- When: 削除 API を呼ぶ
- Then: 認可エラー（権限がありません）

### デフォルトカテゴリの自動コピー

**正常系: 家計簿作成時のコピー**

- Given: メンバーシップを持たない認証済みユーザー
- When: 家計簿作成 API を呼ぶ
- Then: Household 作成・Admin Membership 作成と同じトランザクション内で、デフォルトカテゴリ一覧が Category として一括 INSERT される

**異常系: コピー失敗時のロールバック**

- Given: 家計簿作成中にカテゴリの INSERT が失敗
- When: トランザクション実行
- Then: Household / Membership 作成もロールバック
