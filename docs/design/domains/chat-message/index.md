# チャット

家計簿に紐付くグループチャット機能。所属メンバー全員が参加する 1 つのチャットルームでメッセージを送受信する。
既読状態（誰が読んだか）とオンライン状態（最終アクセスからの経過時間）を扱う。Push 通知は LINE 公式アカウント経由で配信される。

## ユースケース

- メッセージを送受信する（Active メンバーのみ送信可、所属メンバー全員受信）
- 既読状態を確認する（自動既読化、LINE 風）
- オンライン状態を確認する（最終アクセスから N 分以内で判定）
- Push 通知を受け取る（通知 ON の受信メンバーのみ）

## 主な業務制約

- 1 家計簿につきチャットルームは **1 つだけ**（明示的なルームエンティティは持たず、HouseholdID で識別）
- メッセージの **編集・削除は v1 では行わない**（送信したらそのまま、確定事項）
- 退会済みユーザーが過去送信したメッセージは家計簿に残り、送信者は「退会済みユーザー」として表示される
- 自動既読化: チャット画面表示時、未読メッセージに対してサーバーで `ChatRead` を一括 INSERT
- Push 通知: 送信者以外で `PushNotificationEnabled=true` の Active メンバーにのみ配信
- オンライン判定: `LastSeenAt` が現在時刻 - **5 分**（暫定）以内なら ONLINE
