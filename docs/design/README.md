# 設計ドキュメント

ドメインごとの設計ドキュメントを管理する。

## ドメイン一覧

| ドメイン | 概要 | ドキュメント |
|---------|------|-------------|
| ユーザー (User) | LINE ログインで認証する利用者 | _未作成_ |
| 家計簿 (Household) | 収支を共有管理する単位 | _未作成_ |
| メンバーシップ (Membership) | ユーザーと家計簿の所属関係（ロール: 管理者 / メンバー） | _未作成_ |
| カテゴリ (Category) | 収入／支出の分類（家計簿レベル管理） | _未作成_ |
| 収支明細 (Entry) | 1 件の収入または支出（所有者・代理入力対応） | _未作成_ |
| 予算 (Budget) | 支出カテゴリの月次予算 | _未作成_ |
| 招待 (Invitation) | 招待 URL（24 時間・1 回限り） | _未作成_ |
| チャット (ChatMessage) | 家計簿のグループチャットメッセージ | _未作成_ |

> 各ドメインの詳細設計は sudo モデリング（`/review-design`）を経て確定させる。要件の根拠は [要件定義書](../要件定義書.md) を参照。
