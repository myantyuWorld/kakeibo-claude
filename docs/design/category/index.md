# カテゴリ

収支明細を分類する単位。家計簿レベルで管理され、管理者が追加・編集・削除する。
収入カテゴリと支出カテゴリの 2 系統を持つ。

## ユースケース

- カテゴリを追加する（管理者のみ）
- カテゴリを編集する（管理者のみ）
- カテゴリを削除する（管理者のみ。明細が紐付くカテゴリは削除不可）
- 家計簿作成時にデフォルトカテゴリを自動コピーする（システム動作）

## 主な業務制約

- 家計簿レベル管理: 管理者のみ追加・編集・削除可能
- 種別: 収入 / 支出（家計簿作成後の変更不可）
- 削除拒否ルール: そのカテゴリを参照する収支明細が 1 件でも存在する場合は削除不可（QA-D1）
- 重複防止: 同一家計簿・同一種別内でカテゴリ名は一意
